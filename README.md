# ILAHI Computer Center – CSC Portal
Java Servlets + JDBC + MariaDB/MySQL + HTML/CSS/JS

## GitHub Codespaces mein chalana
1. Repo GitHub par push karein → Code → Codespaces → Create.
2. Setup apne aap hoga (Java 17, Maven, MariaDB). Phir terminal:  `mvn jetty:run`
3. Port 8080 khulega. Tables aur services pehli baar apne aap ban jaate hain.
Admin login: `admin` / `admin123` (turant badlein). User: Sign up se banayein.
DB badalna ho: env `DB_URL`, `DB_USER`, `DB_PASS`.
